# 台股收盤後儀表板

每天台灣時間 **14:30** 由 GitHub Actions 自動執行，不需要自己的電腦開機。

## 架構

```text
TWSE OpenAPI
   ↓
GitHub Actions（週一～週五 14:30）
   ↓
資料日期驗證 → 未完成自動重試
   ↓
產生 docs/data/latest.json + history.json
   ↓
GitHub Pages
   ↓
固定網址 → 可貼到 LINE
```

## 目前功能

- 加權指數：收盤、漲跌點、漲跌幅
- 市場廣度：上漲 / 下跌 / 平盤家數
- 成交金額
- 漲幅前 10、跌幅前 10、成交金額前 10
- 關注清單：0050、2330、2317、2454、2308、2382，可自行修改
- 類股強弱排名
- 證交所最新新聞
- 規則式「趨勢思考」：結合今日漲跌、近 5 / 20 交易日指數與成交量能
- 每日歷史摘要累積，供後續做趨勢圖與更完整訊號
