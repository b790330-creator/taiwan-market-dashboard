# 台股星圖｜ETF 收盤後儀表板

以 ETF 為主、正2獨立呈現的台股收盤後儀表板，自己看盤用。正式網站：[台股星圖](https://b790330-creator.github.io/taiwan-market-dashboard/)。

資料全部來自證交所（TWSE）官方資料，每天收盤後由 GitHub Actions 在雲端自動更新；電腦關機不影響。可「加入主畫面」當成手機 APP 使用。

## 資料流程

```text
TWSE 官方資料（盤後 RWD 下載 + OpenAPI）
   ↓
GitHub Actions（週一～週五晚間，每 2 小時一次、共 5 次）
   ↓
update.py → docs/data/*.json
   ↓
GitHub Pages（docs/）
   ↓
手機 APP / 網頁
```

### 更新排程

台北時間 **18:17、20:17、22:17、00:17、02:17**（cron 為 UTC，避開整點以減少 GitHub 延遲）。每次執行先檢查有沒有新的交易日資料，沒有就直接結束，所以多跑幾次幾乎沒有成本。凌晨 6 點前的執行算前一個交易日。

GitHub 的排程偶爾會延遲或漏跑；沒更新時到 Actions 頁面選 **Run workflow** 手動執行即可（勾選「強制執行」會忽略「今天已存過」的檢查）。

### 資料檔（`docs/data/`）

| 檔案 | 內容 |
| --- | --- |
| `latest.json` | 最新交易日的全部儀表板資料（網站讀這個） |
| `predictions.json` | 「大膽預測」每日預測紀錄與隔日驗證結果（最多保留 120 筆） |
| `industry.json` | 上市公司產業別對照表（抓取失敗時的備援） |

## 功能

- **大盤總覽**：加權指數、成交金額、漲跌家數、市場熱度分數。
- **ETF 優先**：ETF 成交金額、漲幅、跌幅排行；**正2 ETF** 自動辨識並獨立排行。
- **個股**：漲幅、跌幅、成交金額、成交量排行；點進去看收盤、漲跌、成交量值與**產業別**（上市個股）。
- **強弱類股**、公開市場資訊。
- **💰 資金流向**：全市場融資、融券、融資金額餘額與當日增減；點進去有白話說明與今日解讀。融資融券通常比股價資料晚公布，之後的排程會自動補上。
- **🎯 大膽預測**：規則式推估明日加權指數上漲機率（限制在 40～62%）。點進去可看計算過程、白話解釋與歷史預測 vs 實際結果、命中率。
- **🃏 明日台股塔羅**：三張牌翻牌（大盤運、ETF 運、資金運）、星運指數、幸運 ETF／時段／數字／顏色、牌卡圖鑑與連續抽牌天數（存在瀏覽器本機）、一鍵複製分享。純娛樂。
- **APP 模式**：PWA，可加入手機主畫面；永遠先抓最新資料，離線時才顯示上次內容。

## 專案結構

```text
update.py                      資料抓取與產生 JSON
.github/workflows/update.yml   排程與自動 commit
docs/index.html                前端（單一檔案）
docs/manifest.webmanifest      PWA 設定
docs/sw.js                     Service Worker
docs/icons/                    APP 圖示
docs/data/                     產生的資料
```

本機測試：`python3 update.py`（需能連到 twse.com.tw）；網頁用 `python3 -m http.server -d docs` 開啟。

## 已知限制

- 融資融券、產業別來源為證交所上市資料；上櫃（TPEX）尚未納入。
- ETF 成分股占比沒有官方來源（只在各投信網站），暫不提供。
- 預測規則為簡化的經驗法則，未經完整回測，命中率以實際累積紀錄為準。
- 目前只保存最新一日快照，沒有個股歷史價格，因此尚無 MA5/20/60 等均線。
