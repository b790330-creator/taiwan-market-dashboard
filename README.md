# 台股收盤後儀表板

以 ETF 為主、正2獨立呈現的台股收盤後儀表板。正式網站：[台股星圖](https://b790330-creator.github.io/taiwan-market-dashboard/)。

每天台灣時間約 **14:30** 由 GitHub Actions 在雲端執行；電腦關機不影響更新。

## 資料流程

```text
TWSE 官方資料（OpenAPI + 盤後 RWD）
   ↓
GitHub Actions（週一～週五 14:30，資料未齊時自動重試）
   ↓
docs/data/latest.json（僅保留最新交易日）
   ↓
GitHub Pages
   ↓
手機 / 電腦 / LINE 固定網址
```

## 已完成

- 雲端自動更新：資料檔只覆寫 `latest.json`，不保存或回補歷史資料。
- 官方收盤資料：加權指數、成交金額、市場廣度、漲跌幅排行與成交量排行。
- ETF 優先：ETF 成交金額、漲幅、跌幅排行；正2 ETF 另外列出漲幅及成交金額排行。
- 點擊排行商品可查看當日收盤、漲跌、成交量與成交金額。
- 「今日一頁重點」：濃縮大盤定位、ETF 焦點、正2風向與明日先看方向。
- 手機緊湊版：雙欄卡片佈局，排行預設只顯示前 3 名，按鈕可展開完整排行。
- 今日市場熱度、強弱類股與公開市場資訊。
- 趣味功能「明日台股塔羅」：每次抽牌隨機產生觀察節奏，並標示「這是趣味性，非投資建議」。

## 後續規劃

以下功能都以**當日最新快照**為基礎，不建立歷史資料庫或回測資料：

1. 我的 ETF：可在瀏覽器本機設定自選 ETF，不上傳也不保存到雲端。
2. ETF / 正2 快速篩選：依當日漲跌、成交金額、成交量切換排行。
3. 三大法人當日買賣超：以官方每日資料呈現外資、投信、自營商，僅看當日數字。
4. TPEX 上櫃市場：把上櫃 ETF 與個股併入當日總覽。
5. 一鍵分享摘要：將「今日一頁重點」整理成可貼到 LINE 的文字。
6. ETF 詳情加強：顯示當日基本行情、商品類型與官方相關資訊。

> 本工具整理公開資訊與當日統計，不提供自動下單，也不構成投資建議。
